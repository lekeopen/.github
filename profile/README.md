# 👋 乐可开源 · LekeOpen

乐可开源是一家位于中国天水的软件与 AI 工程公司。

我们专注于本地优先工具、教育软件、知识系统与生产级 AI 应用，持续把真实产品、工程方法和可复用能力开放出来。

[公司官网](https://lekeopen.com) · [产品与项目](https://lekeopen.com/products/) · [技术动态](https://lekeopen.com/news/) · [联系我们](https://lekeopen.com/contact/)

## 🚀 核心产品

- [**乐可点名**](https://lekeopen.com/products/leke-picker/)：本地优先的课堂随机点名工具；[公开源码](https://github.com/lekeopen/leke-picker)，Apache-2.0。
- [**归个类**](https://lekeopen.com/products/guigelei/)：本地文件智能整理工具；[官方版本发布与下载](https://github.com/lekeopen/guigelei-releases)，不代表完整源码开放。
- [**小乐 AI**](https://docs.xiaole.app)：具备记忆与行动能力的个人 AI 助手；提供公开文档，不宣称完整源码开放。
- [**乐教库**](https://lejiaoku.com)：面向 K12 教育场景的教学资源平台。
